# Nasko's Site for HackClub Stardance Programme

I am creating this GitHub repo to contain my personal site files that I wrote for this project.

Creator: **@Nasko**

# Features

- An adaptation of *ticket shape* could be seen in left and middle sections.
- An interactive *navigation bar* is present on left that could browse between sections.
- A *color palette* consisting of tonnes of blue is used for a better look. I acquired this color palette from ColorHunt.
- Descriptions and an image inside those shapes.
- Three flex boxes dividing the site into 3 with ratio 1:3:1 as right:middle:left.
- Two working links one pointing into this GitHub page and one poiting to my GitHub page.
